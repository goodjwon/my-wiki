# workout-history — 원본 자료 인덱스

Workout History 앱(iOS 1.0, 2026-08-19 심사 제출)의 설계·진행 스냅샷.
원본 진실은 앱 저장소 `~/VsCodeProjects/workout-history/docs/` — 여기는 제출 시점 사본.

읽기 순서:
1. `TIMELINE.md` — 출시 여정 회고(이정표·설계 원칙·삽질 로그) ← 시작점
2. `PLANNING.md` — 요구사항(R1~R11)·시나리오·로드맵
3. `CONCEPTS.md` — 개념 모델(종목·목표·세트·루틴·기록의 정의) v1.2
4. `ARCHITECTURE.md` — 레이어·도메인 엔진·워치 통신·성능 예산
5. `BACKLOG.md` — 전 기간 작업 로그(B-01~B-69, 결정 이력 포함)
