- LLM 단계: 대화형 `claude --agent advisor` 대신 같은 요청을 헤드리스로 실행 — `claude --agent advisor -p "<요청>" --allowedTools "Read,Grep,Glob,Edit,Write,Agent,Bash(node *),Bash(git *)" --output-format stream-json --verbose`. 장면 3은 페이지 블록 그대로(`--allowedTools`에 `Task` 표기). ## 3. 관찰

1. **기본편 Step 3 — 4장면 전부 재현.** 브리프 6항목 모두 채움, Write는 Worker만(1회), Worker 보고 뒤 Advisor가 `git status --short && cat cart.js && node cart.test.js`로 재검증(새 파일은 untracked라 `git diff`에 안 나와 `cat` 사용), 커밋은 Advisor. Advisor의 `Bash` 우회(셸로 파일 쓰기)는 0건.
2. **장면 1 — 재위임은 재현, "위임 전 테스트 실행"은 미재현.** Advisor는 `node cart.test.js`를 돌리지 않고 `cat cart.js cart.test.js`로 읽어 실패를 파악했다. 대신 브리프에 현재 동작·기대값(40000)·고칠 줄·위치 함정을 담았다. 수정은 Worker Edit 1회, Advisor는 `git diff`+재테스트 후 커밋.
3. **장면 2 — 병렬 재현.** Advisor의 한 메시지에 위임 호출 2개. 브리프 [범위 경계]가 모듈별로 분리. 재검증·커밋도 모듈별(커밋 2개).
4. **장면 3 — 환경 변수가 frontmatter를 덮어쓰지 않음.** 3-1에서 Worker 6건 haiku, 3-2에서 `CLAUDE_CODE_SUBAGENT_MODEL=claude-opus-5-5`를 설정해도 Worker 7건 모두 haiku. 공식 문서(sub-agents)의 "2.1.251부터 frontmatter가 환경 변수보다 우선, 그 이전엔 환경 변수가 먼저"와 일치. 2026-07-12(2.1.197)의 "덮어씀" 실측은 옛 버전 동작 → 심화편 장면 3·기본편 모델 메모·`raw/ai-engineering/ai-advisor/claude_script.md`에 교정 반영.
5. **장면 4 — 오버헤드 예외 재현.** 위임 0회, Advisor가 Read → Edit → `git diff`. 요청이 없어 커밋하지 않았고, 장면 3에서 바뀐 `worker.md`가 미커밋이라는 점을 보고에서 짚음.
6. **`Task`·`Agent` 이름.** 정의 파일·`--allowedTools`에 `Task`로 적어도 위임이 동작했고(별칭), stream-json에는 `Agent`로 기록됐다. 공식 문서: 2.1.63에서 이름 변경, `Task`는 별칭으로 유지.
7. **시간.** 대부분 4~7분(265~399초). 장면 2만 28초였다. 원인은 이 로그로 확정하지 못했다.
