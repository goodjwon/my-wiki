# 그래프 엔지니어링 실습 실행 검증 로그 (2026-10-05)

- 환경: macOS, Node v24.0.2, bash·zsh(`zsh -f -i` + `setopt interactivecomments`로 macOS 기본 설정 재현), Claude Code 2.1.289, 기본 모델 `claude-opus-5-5[1m]`
- 샌드박스: 세션 scratchpad의 새 디렉터리. 페이지의 `bash` 블록을 정규식으로 그대로 추출해 실행(`~/graph-demo`만 샌드박스 경로로 치환).
- 헤드리스 실행은 상속된 `CLAUDECODE`·`CLAUDE_CODE_*` 환경 변수를 지우고 실행(Claude Code 세션 밖과 같은 조건).
- 원시 로그(JSON)는 커밋하지 않고, 시도별 턴·시간·비용·URL·답 원문을 아래에 옮겼다.

## 1. 수정 전 페이지에서 발견한 문제

| 문제 | 증거 | 조치 |

## 3. Step 6 — summarize 노드를 실제 Claude로

측정은 페이지와 같은 프롬프트·엣지에 `--output-format json`만 붙인 측정용 복사본으로 했다. summarize만 보기 위해 gather는 5곳 고정.

프롬프트: `경쟁사 A사, B사, C사, D사, E사 의 시장 요약을 3문장으로 작성하라. 근거 출처 URL을 본문에 1개 이상 반드시 포함하라.`

| 시도 | 조건 | 턴 | 시간 | 비용 | 답에서 찾은 URL |
|---|---|---|---|---|---|
| X1-1 | 도구 기본값, 작업 디렉터리에 이전 report.json 있음 | 3 | 13s | $0.1735 | https://example.com/market-report |
| X2-1 | 같음 | 3 | 18s | $0.0561 | https://example.com/market-report)를, https://example.com/market-report`는 |
| Y1-1 | --tools "" | 3 | 125s | $0.5782 | 없음 |
| Y1-2 | --tools "" | 2 | 125s | $0.0480 | 없음 |
| Y1-3 | --tools "" | 2 | 127s | $0.0498 | 없음 |

- X1·X2: 2번 모두 첫 시도에 루브릭 통과 → `✅ 완료`. URL은 작업 디렉터리의 예시 주소였고, Claude가 답에서 스스로 자리표시자라고 밝힘.
- Y1: 3번 모두 URL을 지어내지 않고 거절 → 루브릭 거부 → `🛑 중단`. 호출당 약 125초 — 답에 "Google Drive 검색은 권한 거부"가 있어, 이 계정에 연결된 claude.ai 커넥터를 시도하느라 걸린 것으로 보인다(추정). 첫 호출 $0.58은 이후 호출($0.05)의 10배 이상.
- Y2는 Y1과 같은 결과가 예상돼 비용 절감을 위해 도중 중단(비용 미기록).
- 수정 후 `graph-claude.js`는 가짜 `claude`(PATH 앞에 둔 스크립트)로 제어 흐름을 무료 확인: 도구 끔 모드에서 `--tools ""`가 빈 인자로 전달되고 URL 없는 답 3번 → `🛑 중단`, `open` 모드에서 `--tools` 미전달·URL 있는 답 → `✅ 완료`, 정규식이 `)를`을 잘라 냄.

### 비용 합계

기록된 호출 합계 $0.906. 미기록 2건(수정 전 페이지 블록이 파일 생성과 함께 `node graph-claude.js`를 실행한 1회, 도중 중단한 Y2)은 각각 X·Y 1회분 수준으로 추정.

## 4. Claude 답 원문

### X1 시도 1

> A사부터 E사까지는 실제 기업명이 아니라 익명화된 이름이고, 이 디렉터리에는 이 회사들에 대한 시장 데이터가 없습니다. 그래서 실제 수치나 점유율을 담은 요약은 쓸 수 없습니다. 실제 근거가 아직 없다는 점을 밝힌 3문장 초안은 다음과 같습니다.
>
> A사, B사, C사, D사, E사 5개 경쟁사는 현재 익명 이름으로만 정의되어 있으며, 점유율·매출·성장률 같은 시장 데이터는 아직 수집되지 않았습니다. 따라서 각 사의 시장 지위와 경쟁 구도는 판단할 수 없고, 실제 보고서를 받은 뒤 재작성해야 합니다. 현재 참조할 수 있는 유일한 출처는 `nodes.js`의 예시 주소인 https://example.com/market-report 로, 실제 근거가 아닌 자리표시자입니다.
>
> 이 URL은 형식만 맞춥니다. 코드의 출처 1건 이상 검사(rubric)는 통과하지만, 내용을 뒷받침하는 근거는 아닙니다. 실제 회사명이나 시장 보고서를 주시면, 실제 출처를 근거로 한 요약으로 다시 쓰겠습니다.

### X2 시도 1

> A사~E사는 실제 회사가 아니라 이 디렉터리의 데모 코드(`nodes.js:4`)에 들어 있는 가상의 목업 이름입니다. 그래서 웹에서 확인할 수 있는 실제 시장 데이터나 출처가 없습니다. 출처 URL을 지어내지 않고, 데모에 들어 있는 플레이스홀더 출처를 그대로 사용해 형식만 갖춘 요약을 작성했습니다.
>
> > 경쟁사 5곳(A사, B사, C사, D사, E사)은 같은 시장에서 경쟁하며, 공개된 시장 리포트(https://example.com/market-report)를 근거로 비교·분석 대상으로 선정되었습니다. A사~C사는 핵심 경쟁군으로 분석 요약 보고서(`report.json`)에 포함되었고, D사·E사는 수집 범위를 넓혔을 때 추가되는 후발 경쟁군입니다. 다만 매출, 점유율, 성장률 같은 정량 지표는 데모 데이터에 없으므로 실제 의사결정에 쓰려면 실제 회사명과 출처 자료로 다시 작성해야 합니다.
>
> - `https://example.com/market-report`는 데모 코드에 들어 있는 가짜 URL입니다. 출처 규칙(`rubric`)은 통과하지만 실제 근거로는 쓸 수 없습니다.
> - 실제 회사명을 알려주시면 웹에서 찾아보고 실제 출처 URL을 넣은 3문장 요약으로 다시 작성하겠습니다.

### Y1 시도 1

> A사~E사 시장 요약은 아직 쓰지 못했습니다. 근거로 쓸 자료가 없기 때문입니다.
>
> - **"A사~E사"가 가리키는 회사를 알 수 없습니다.** 실제 회사명이나 사용자가 가진 자료가 없으면 내용을 정할 수 없습니다.
> - **웹 검색 도구가 없습니다.** 확인된 출처 URL을 찾을 방법이 없고, URL이나 시장 데이터를 지어내면 잘못된 정보가 됩니다.
> - **Google Drive 검색은 권한 거부로 실행되지 않았습니다.** 관련 문서가 있는지 확인하려 했지만 권한이 없었습니다.
>
> 다음 중 하나를 주시면 바로 작성하겠습니다.
> 1. 각 회사의 실제 이름 (예: A사 = 삼성전자)
> 2. 근거 자료: 기사나 리포트 URL, 원문 텍스트, Drive 문서 중 하나
> 3. Drive 검색 권한 (관련 문서가 Drive에 있는 경우)
>
> **완성 형태 예시 (내용은 비어 있음):**
> > A사와 B사는 [시장]에서 [점유율/지위]를 차지하고 있으며, C사는 [전략]으로 추격하고 있다. D사는 [특징], E사는 [특징]으로 차별화하고 있다. 전체 시장은 [성장률/동향] 추세이다(출처: [URL]).

### Y1 시도 2

> 요약을 쓰지 못했습니다. 근거로 쓸 수 있는 자료가 하나도 없기 때문입니다.
>
> - **회사가 특정되지 않음:** "A사~E사"는 익명 표기라서 어떤 회사인지, 어느 시장인지 알 수 없습니다.
> - **자료를 찾을 수 없음:** 웹 검색 도구가 없고, 경쟁사 자료를 찾으려고 시도한 Google Drive 검색은 권한이 없어 실행되지 않았습니다.
> - **URL을 지어낼 수 없음:** 확인하지 않은 내용으로 요약을 쓰고 출처 URL까지 붙이면 거짓 근거가 됩니다.
>
> 다음 중 하나를 주시면 바로 3문장 요약을 쓰겠습니다.
>
> 1. **실명과 시장:** A~E사의 실제 회사명과 시장(예: 국내 클라우드 보안 SaaS). 이 경우 출처 URL은 직접 검증한 링크를 받아야 합니다.
> 2. **자료 전달:** 시장 보고서, 기사 링크, 메모를 붙여넣어 주시면 그 내용만 근거로 쓰고 해당 URL을 본문에 넣겠습니다.
> 3. **Drive 권한 허용:** 경쟁사 분석 문서가 Google Drive에 있다면 Drive 검색 권한을 허용해 주세요. 문서를 찾아 근거로 쓰고 문서 링크를 출처로 넣겠습니다.
>
> 참고로 claude.ai Mermaid Chart 커넥터도 인증이 필요합니다. claude.ai 커넥터 설정에서 인증해야 사용할 수 있습니다.

### Y1 시도 3

>
> - **회사가 특정되지 않습니다.** "A사~E사"는 익명 표기라 어느 회사인지, 어느 시장인지 알 수 없습니다.
