# raw/ai-engineering/

AI 활용·에이전트 설계 관련 원본 자료를 모은 우산 디렉터리. 각 주제가 단독으로는 자료 수가 적어 하위 디렉터리로 통합했다 (2026-08-10).

## 자료 구성

| 디렉터리 | 주제 | 자료 수 |
|----------|------|---------|
| `harness-engineering/` | 하네스 엔지니어링 실습 커리큘럼 (슬라이드·강의교안·튜터 프롬프트·5모듈 실습 키트) | 7 |
| `2bun-coding/` | 2분코딩 채널 CS 주제 노트 (502 타임아웃·커넥션 풀·QUIC·트랜잭션 롤백 등) | 8 |
| `ai-advisor/` | Advisor–Worker 협업 모델 에이전트 스크립트 + 프로젝트 지침 템플릿 | 4 |
| `loop-engineering/` | 루프 엔지니어링 정리 노트 + 1차 출처 목록 | 2 |
| `grap-engineering/` | 그래프 엔지니어링 — 단일 LLM 한계를 넘는 멀티 에이전트 그래프 설계 | 1 |
| `llm-wiki-pattern/` | LLM으로 개인 지식 베이스를 구축하는 패턴 (아이디어 원문, 영문) | 1 |
| `claude-design/` | 클로드로 디자인 시스템·와이어프레임 만들기 (영상 자막) | 1 |

각 하위 디렉터리의 상세 구성은 해당 디렉터리의 `README.md`를 참조 (있는 경우).
