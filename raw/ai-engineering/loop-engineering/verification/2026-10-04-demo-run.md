## 2. Step 6 — 셸 루프 + `claude -p`

### 발견한 함정 1: `--allowedTools`에 `Write` 누락

기존 페이지 명령(`--allowedTools "Read,Edit,Bash(node *)"`)과 같은 계열인 `"Read,Edit"`로 실행하자, Claude가 파일 전체를 Write로 다시 쓰려다 막혀 사이클마다 같은 실패가 반복됐다. 사이클 1 실제 출력:

```
── 사이클 1 ──
  ❌ isPalindrome("RaceCar") = false (기대값 true)
  ❌ isPalindrome("A man, a plan, a canal: Panama") = false (기대값 true)
  ❌ isPalindrome("No lemon, no melon") = false (기대값 true)
FAIL — 3개 케이스 실패
↻ 실패 — 실패 기록을 Claude에게 넘겨 수정을 맡긴다
`solution.js`는 고치지 못했습니다. 파일 쓰기와 테스트 실행 권한이 둘 다 거절됐습니다.

**실패 원인:** `module.exports = (s) => s === [...s].reverse().join('');`는 입력 문자열을 정리하지 않고 그대로 뒤집어 비교합니다. 그래서 대소문자(`R`와 `r`)와 공백, 구두점이 비교에 그대로 들어가고, 이 3개 케이스가 실패합니다.

**수정안** (`solution.js` 전체 교체):
```js
module.exports = (s) => {
  const t = s.toLowerCase().replace(/[^\p{L}\p{N}]/gu, '');
  return t === [...t].reverse().join('');
};
```
소문자로 바꾸고 문자와 숫자만 남긴 뒤 뒤집어 비교합니다. 정규식이 유니코드 문자도 인식하므로 영어가 아닌 입력도 처리됩니다.

이 코드로 `node test.js`를 돌려 본 적은 없습니다. 쓰기 권한을 주시면 바로 적용하고 테스트까지 실행하겠습니다.

참고로, 이번 작업과는 관계없지만 claude.ai의 Mermaid Chart 커넥터를 쓰려면 claude.ai 커넥터 설정에서 먼저 인증해야 합니다.
```

→ 페이지를 `--allowedTools "Read,Edit,Write"`로 교정.

── 사이클 2 ──

### 관찰

1. **9번 모두 첫 수정에 정답** — 이 문제는 Claude에게 쉬워서 "실패 → 재수정" 반복은 한 번도 일어나지 않았다. 반복 효과는 이 실험으로 확인하지 못했다.
2. **A(권한 없음)**: 3번 모두 Claude가 스스로 `node test.js`를 실행하려다 거부됐고, "고쳤지만 테스트로 확인하지 못했다"고 보고했다. 코드는 맞았지만, 확인된 근거는 없다.
3. **A'(권한 있음)**: 루프 지시가 없어도 3번 모두 스스로 테스트를 실행해 PASS를 확인하고 보고했다. → 이 조건에서 결과를 가른 것은 프롬프트 문구보다 **테스트 실행 권한**이었다.
4. **B(루프 프롬프트)**: 3번 모두 첫 동작이 `solution.js`·`test.js`를 바로 읽는 것이었다(A·A'는 `ls`·`grep`으로 무엇을 확인할지 찾아다님). 도구 호출은 3회로 가장 짧았다. 최종 답에 `PASS — 6개 케이스 전부 통과` 출력 원문을 붙인 것은 B 3/3, A' 0/3 — A'는 테스트를 돌리고도 "통과했다"는 문장으로만 보고했다. 루프 프롬프트가 만든 차이는 "말"이 아닌 "증거"로 보고하게 한 것이다.
5. **시간**: A는 3번 모두 약 2분(127~137초) 걸렸고, 권한이 있는 A'·B는 10~16초였다. 원인은 이 로그로 확정하지 못했다(거부된 실행 요청 처리로 추정).
6. **재현 블록 확인**: 페이지 6-5의 헤드리스 재현 블록을 그대로 추출해 `prompt-loop.txt` 생성(실험 프롬프트와 diff 동일) + ② 줄 1회 실행 → 최종 답에 "통과한 테스트 출력: PASS — 6개 케이스 전부 통과" 원문, 실행 후 실제 테스트 PASS.
7. **잡음**: 몇몇 답 끝에 "claude.ai의 Mermaid Chart 커넥터 인증" 안내가 붙었다. 이 계정의 claude.ai 커넥터 설정에서 온 문구로, 실습과 무관하다.

    >
    > ```js
    > module.exports = (s) => {

    >
    > **수정:** 비교 전에 소문자로 바꾸고 문자와 숫자만 남기도록 했어. 영어 외의 문자(한글 등)도 지워지지 않고 그대로 비교돼.
