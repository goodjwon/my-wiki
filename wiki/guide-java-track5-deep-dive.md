## 🧪 트랙 마무리 — 과제 3. 견적·계약 업무

T1~T4를 모두 동원하는 종합 과제로, [[guide-java-practice-layered-quotation]]에서 4계층 아키텍처와 Command/Query 분리를 MyBatis로 구현합니다. 물품·견적 업무 규칙을 도메인에 두고, 계층 의존 방향을 ArchUnit 테스트로 자동 검사합니다. 11.15·11.18의 Git 브랜치·작은 커밋 습관을 이 과제에 그대로 적용합니다.

**보충 연습** (포트폴리오용 토이프로젝트, 하나를 골라 끝까지):

- 11.25 / 11.23 블로그 작성하기 — Java/JSP(Model 1) CRUD로 웹의 전 과정 → [[java-study-ch11]]
- 11.19 온라인 게임 토이 프로젝트 — 객체 협력·파일/네트워크·동시성 종합 → [[java-study-ch11]]
- 11.26 메모 앱 — T2 버전을 저장·검색·테스트 가능 구조로 확장 → [[java-study-ch11]]
