## 이 스터디는 무엇인가

2024~2025년에 정리한 Java 학습 자료([[src-java-study-2024-2025]])를 **Java 언어 → Spring 웹 → 고급·품질** 순서의 교재로 재구성한 것입니다. 문법을 외우는 것이 아니라, **왜 그렇게 동작하는지 설명할 수 있는 상태**를 목표로 합니다. 모든 실습은 실제 프로젝트 파일과 실행 명령을 기준으로 진행하고, 명령마다 예상 결과를 함께 적어 스스로 확인할 수 있게 했습니다.

## 챕터·트랙·과제는 어떻게 쓰나

| 구분 | 역할 | 이렇게 씁니다 |
|------|------|--------------|
| 챕터 (ch01~ch11) | 주제별 본문 | 순서대로 읽거나, 필요한 주제를 찾아봅니다 |
| 트랙 (T1~T5) | 챕터를 묶은 학습 코스 | 흐름·핵심 개념·체크리스트로 진도를 점검합니다 |
| 과제 (🧪 3개) | 트랙 마무리 실습 | 여러 챕터의 내용을 프로젝트 하나로 확인하고 테스트로 스스로 채점합니다 |

단계·챕터·트랙·과제의 대응은 [[guide-java-learning-path]]에 한 표로 정리되어 있습니다. 본인 수준에 맞는 트랙부터 시작해도 됩니다.
